Color Picker

Each panel shows the setup call and then that very call running. Open a swatch, pick a color — the surface under the snippet repaints as you drag.

01One color — the default

No slots: one slot named color, one trigger, one preset grid and no tab row. colors.color is the only value to paint.

Setup

import ColorPicker from './src/color-picker.js';

const oneHeadline = document.getElementById('oneHeadline');

const onePicker = new ColorPicker({
  triggers: '#oneTriggers',
  initialColors: { color: '#0F766E' },
  onChange: (colors) => { oneHeadline.style.color = colors.color; },
});

oneHeadline.style.color = onePicker.getColors().color;

02A pair — text over panel

Two slots, so there is a tab per slot. contrastPair turns on the suggestions panel: it offers colors that keep the pair readable, and it is a choice — no pair, no suggestions.

Setup

import ColorPicker from './src/color-picker.js';

const pairTag = document.getElementById('pairTag');
const pairPanel = document.getElementById('pairPanel');

const paintPair = (colors) => {
  pairTag.style.color = colors.text;
  pairTag.style.background = colors.background;
  pairPanel.style.color = colors.text;
  pairPanel.style.background = colors.background;
};

const pairPicker = new ColorPicker({
  triggers: '#pairTriggers',
  slots: [
    { id: 'text', label: 'Text color', symbol: 'Aa', presetSet: 'text' },
    { id: 'background', label: 'Panel background', symbol: '▰', presetSet: 'background' },
  ],
  initialColors: { text: '#0F766E', background: '#CCFBF1' },
  showContrastSuggestions: true,
  contrastPair: ['text', 'background'],
  onChange: paintPair,
});

paintPair(pairPicker.getColors());

03Brand palette — dark theme, own presets

Three slots, and presets replaces a named category in each group instead of adding one. theme: 'dark' swaps the panel and trigger tokens; the host still reads one key per slot.

Setup

import ColorPicker from './src/color-picker.js';

const brandChip = document.getElementById('brandChip');

const paintBrand = (colors) => {
  brandChip.style.color = colors.text;
  brandChip.style.background = colors.background;
  brandChip.style.borderColor = colors.accent;
};

const brandPicker = new ColorPicker({
  triggers: '#brandTriggers',
  container: '#brandRoot',
  theme: 'dark',
  showContrastSuggestions: true,
  contrastPair: ['text', 'background'],
  slots: [
    { id: 'text', label: 'Brand text', symbol: 'Aa', presetSet: 'text' },
    { id: 'background', label: 'Brand panel', symbol: '▰', presetSet: 'background' },
    { id: 'accent', label: 'Accent', type: 'Accent', symbol: '✦', hint: 'Borders and links' },
  ],
  initialColors: { text: '#0B3D2E', background: '#FDE68A', accent: '#7C3AED' },
  presets: {
    text: { Brand: ['#0B3D2E', '#134E4A', '#1E3A5F', '#4C1D95'] },
    background: { Brand: ['#FDE68A', '#FEF3C7', '#E0F2FE', '#FCE7F3'] },
  },
  onChange: paintBrand,
});

paintBrand(brandPicker.getColors());

04Product section — four slots, one popup

Two slots share presetSet: 'background': a section surface and a card surface take the same kind of palette and still get a tab each, told apart by label. Every color on the surface below is one of the four.

Setup

import ColorPicker from './src/color-picker.js';

const sheet = document.getElementById('sheetSection');

const paintSheet = (colors) => {
  sheet.style.setProperty('--sheet-heading', colors.heading);
  sheet.style.setProperty('--sheet-surface', colors.surface);
  sheet.style.setProperty('--sheet-card', colors.card);
  sheet.style.setProperty('--sheet-accent', colors.accent);
};

const sheetPicker = new ColorPicker({
  triggers: '#sheetTriggers',
  container: '#sheetRoot',
  theme: 'light',
  showContrastSuggestions: true,
  contrastPair: ['heading', 'surface'],
  slots: [
    { id: 'heading', label: 'Heading', symbol: 'Aa', presetSet: 'text' },
    { id: 'surface', label: 'Section bg', symbol: '▰', presetSet: 'background' },
    { id: 'card', label: 'Card bg', symbol: '▰', presetSet: 'background' },
    { id: 'accent', label: 'Accent', type: 'Accent', symbol: '✦', hint: 'Links, borders, tags' },
  ],
  initialColors: { heading: '#1E293B', surface: '#EEF2FF', card: '#FFFFFF', accent: '#7C3AED' },
  onChange: paintSheet,
});

paintSheet(sheetPicker.getColors());

05Your own inputs — Coloris style

Point fields at inputs that already exist: each one becomes a slot named by data-slot, then its id, and the field itself is the trigger — no bar to mount. Values are written back as HEX with a native input event, so a framework bound to the field sees the change.

Setup

import ColorPicker from './src/color-picker.js';

const fieldPreview = document.getElementById('fieldPreview');

const fieldPicker = new ColorPicker({
  fields: '[data-color-picker]',        // selector, element or NodeList
  onChange: (colors) => {
    fieldPreview.style.color = colors.ink;
    fieldPreview.style.background = colors.wash;
  },
});

fieldPreview.style.color = fieldPicker.getColors().ink;
fieldPreview.style.background = fieldPicker.getColors().wash;

Live

Click a field to open the picker on that slot; typing a HEX commits it.

06A whole page — live contrast

The text color and the panel background are written to two custom properties, and everything below reads them. A pill reports the pair's WCAG level, measured with the library's own contrastRatio.

Setup

import ColorPicker from './src/color-picker.js';
import { parseHex } from './src/color.js';
import { contrastRatio, wcagLevel, formatRatio } from './src/contrast.js';

const picker = new ColorPicker({
  triggers: '#pageTriggers',
  slots: [
    { id: 'text', label: 'Text color', symbol: 'Aa', presetSet: 'text' },
    { id: 'background', label: 'Panel background', symbol: '▰', presetSet: 'background' },
  ],
  initialColors: { text: '#0F766E', background: '#CCFBF1' },
  showContrastSuggestions: true,
  contrastPair: ['text', 'background'],
  onChange: (colors) => {
    surface.style.setProperty('--pp-fg', colors.text);
    surface.style.setProperty('--pp-bg', colors.background);
    const ratio = contrastRatio(parseHex(colors.text), parseHex(colors.background));
    pill.textContent = wcagLevel(ratio);   // AAA | AA | AA-large | fail
  },
});
